## 1. Overview

> Source PDF page 1

The Vacant Plot to Tender Publication process manages the complete lifecycle of a vacant plot, starting from the identification and selection of the plot through LAC generation, authority approval, Board Note generation, rent calculation, tender generation, and final tender publication.

The process ensures that the plot details, custodian information, proposed use, financial calculations, and required approvals are captured before a tender is published.

## 3. Detailed Process

> Source PDF pages 2-4

### Step 1: Identification of Vacant Plot

MbPA maintains information about vacant plots available for allotment or leasing.

The user can view the available vacant plots and select the plot for which a tender needs to be published.

The plot information may include:

- Plot identification number
- Plot location
- Plot area
- Custodian details
- Current status
- Other relevant property details

### Step 2: Selection of Vacant Plot

The user selects the vacant plot for which the tender process needs to be initiated.

Once the plot is selected, the system retrieves the relevant plot and custodian information required for further processing.

### Step 3: LAC Generation

After selecting the plot, the LAC (Land Allotment Committee) proposal is generated.

The LAC is prepared based on the relevant information associated with the selected plot, including:

- Custodian Information
- Proposal
- Proposed Use
- Plot details
- Other required information

The generated LAC serves as the proposal document for obtaining the required authority approval.

### Step 4: LAC Approval

The generated LAC is forwarded to the concerned authority for review and approval.

The authority reviews the proposal and the information provided in the LAC.

Based on the review:

- The LAC may be approved.
- It may be sent back for modification / clarification, depending on the workflow requirements.

Only after the required LAC approval can the process proceed to the next stage.

### Step 5: Board Note Generation

Once the LAC is approved, an Approved Board Note is generated based on the approved proposal.

The Board Note contains the relevant information required for placing the proposal before the competent authority / Board.

The Board Note is then submitted for the required approval.

### Step 6: Annual Rent / Upfront Amount Calculation

The Annual Rent and/or Upfront Amount is calculated based on the approved LAC details.

The calculation may consider parameters such as:

- Plot area
- Proposed use
- Applicable rate
- Lease period

The calculated financial values are associated with the tender proposal.

### Step 7: Board Note Approval

The Board Note is reviewed by the competent authority.

The proposal can proceed only after the required Board Note approval is received.

If the Board Note is rejected or requires modification, it is returned to the concerned user for necessary action.

### Step 8: Tender Generation

Once the Board Note is approved, the system allows the user to generate the Tender.

The tender is generated using the approved information, including:

- Selected plot details
- Approved proposal
- Proposed use
- Annual rent
- Upfront amount
- Applicable tender conditions

### Step 9: NIT Approval

The generated tender is submitted for NIT (Notice Inviting Tender) approval.

The concerned authority reviews the NIT and verifies the tender details.

The tender can proceed to publication only after the required NIT approval is obtained.

### Step 10: Tender Publication

After receiving NIT approval, the tender is published.

The tender is then made available to prospective bidders according to the applicable tender process.

This marks the completion of the Tender Publication process.
